# V3 视觉系统：Warm Internal Memo

视觉比例：70% 现代轻松娱乐产品，30% 内部文件恶搞。文件、印章和批注只作为装饰语言，不模拟真实行政系统。

## 颜色职责

- 莓粉 `#E94F87`：品牌、人格、主操作；强色 `#C9366F`，浅底 `#FBE4ED`。
- 柔紫 `#89658E`：系统标签、关系鉴定、辅助信息；浅底 `#F0E7F1`。
- 暖黄 `#F0CA6A`：批注、死因、手绘强调；浅底 `#FFF3CA`。
- 奶灰 `#F6F1EA` 与暖白 `#FFFDF9`：页面和纸张。
- 深墨 `#2B2628`：正文。绿色和风险红只用于真实语义状态。

运行时 token 统一定义在 `miniprogram/styles/tokens.wxss`。页面不得重新引入独立品牌色。

## 组件规则

- 卡片：`24rpx` 圆角、暖灰描边、暖色轻阴影。
- 按钮：主按钮莓粉底，次按钮暖白底加莓粉描边，禁用态无阴影。
- 选项：默认暖白，选中后使用浅莓粉；不使用紫色发光。
- 系统标签：柔紫小字号和字距，只承担装饰作用。
- 死因：暖黄便签或审核章，不使用风险红。
- 关系：柔紫左侧档案线，A/B 身份清楚，但不展示兼容度百分比。

## 传播资产

- 单人海报层级：人格名 → 人格金句 → 绩效/死因 → 1–2 条抓包 → 落款。
- 关系海报层级：关系名 → 关系判词 → A/B 人格 → 落款。
- 聊天缩略图为本地 `750 × 600` PNG，不携带动态结果：
  - `miniprogram/assets/share-single.png`
  - `miniprogram/assets/share-relationship.png`

缩略图由 `scripts/generate-share-thumbnails.py` 确定性生成；脚本需要 Pillow，只在修改视觉资产时运行，小程序运行时不依赖 Python。
