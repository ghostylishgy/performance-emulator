# 碳基故障 · 教材产品开发总纲 v1

## 产品边界

- 稳定内部 ID：`textbook_desk`。
- 公开名称只由 `miniprogram/config/products.ts` 的 registry 提供；当前名称为“课本应急箱”，仍可在配置层单点更换。
- 产品帮助家长定位经过人工检查的人教社公开电子教材阅读入口，并将地址复制到浏览器打开。
- 产品同时呈现当前教材、下一册和下一年级/下一学段前瞻，但时间推荐永不自动修改用户保存的当前年级。
- 首发增长重点是小学六年级到初中七年级，不是架构边界。底层 grade/target 模型覆盖普通六三学制小学一至六年级、初中七至九年级。

## 生产原则

- Native WeChat Mini Program；Local-first；Zero Backend；Zero CloudBase；Zero Login。
- FreePEP 只作为离线研究与数据输入，不作为运行依赖。
- 不接入 Playwright、WAF 处理、在线 catalog refresh、教材抓取、PDF 合成或 PDF 下载。
- runtime 只携带经过清洗和人工检查的必要 metadata，不携带原始 789 条 catalog。
- 官方阅读操作固定为 `wx.setClipboardData`；不使用 `web-view` 或任意外链容器。
- 教材产品专属代码和静态数据必须位于 `pages/textbook-desk/` 分包内。

## 首发数据边界

当前 runtime 切片包含 17 条：

- 小学六年级语文、数学、英语上下册 10 条；英语同册保留多个版本。
- 初中七年级上册语文、数学、英语、道德与法治、历史、地理、生物学 7 条。

`verifiedAt` 表示 metadata 与官方阅读 URL 结构已在该日期人工复核，不表示永久可访问，也不表示审定年份、课程标准年份或地区适用性。后续扩展年级必须经过相同的清洗与人工复核流程。

## 事实显示规则

UI 只能显示 `TextbookRecord` 实际存在的字段。没有 `editionNote` 时不得创造以下信息：

- 2024版、最新版、新课标、审定年份、ISBN、页数、全套；
- 武汉主流版本、地区统一教材；
- 官方合作、官方授权或其他关系暗示。

必须保留“请以学校实际发放教材为准”的事实边界。小学英语不得自动选择所谓主流版；版本选择权属于用户。

## MVP 非目标

- 高保真 UI、教材插画、教材封面、复杂 Bottom Sheet 和动画；
- 章节/单元目录、页码搜索、教材详情页；
- PDF 交付、账号、支付、手机号、订阅消息；
- AI 学习、培训、课程或付费教育；
- 收集孩子姓名、家长姓名、学校、班级或剪贴板内容。

## 发布门

教材产品在 UI 和真机验收完成前保持 `enabled=false`、`featured=false`。开启前必须人工确认：

1. 微信后台服务类目与当前产品表述匹配；
2. Analytics 事件已配置并能在后台收到；
3. 目标官方阅读地址在微信真机复制到系统浏览器后可访问；
4. 客服或意见反馈能力若进入 UI，后台已启用；
5. 开发者工具主包、教材分包、总包体积均通过上传检查。
